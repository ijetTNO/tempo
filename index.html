Code reference
game.moveThe move just played: from, to, piece ("wN"), captured ("bP" or ""), promo, castle game.mover / game.turn"white" or "black": who just moved, who moves next game.plyMoves played so far (both sides) game.starttrue once, before the first move, so you can set things up. Otherwise false game.get("e4")Piece there ("wQ"), "" if empty, "#" for a wall game.set("e4","bR")Put a piece on a square game.remove("e4")Clear a square game.wall("e4", true)Add or remove a wall game.find("wK")List squares holding that piece game.pieceCode("Name")Code for your Mod Lab piece by name, as a monster ("nD"). Add "white" or "black" for a side game.count("b")How many black pieces ("bP" counts pawns) game.squares()All 64 square names game.random()Random number, the same for both players online game.stateYour own object that survives between moves game.win("white", why)End the game. Also game.draw(why) game.say("text")Show a message to the players
